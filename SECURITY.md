# Security Policy

## Reporting a vulnerability

If you find a security issue in **Warung Om Tante V2**, please do not open a public issue.

- Use the **Security** tab of this repository and choose **Report a vulnerability** (private report), or
- send a message through [LinkedIn](https://www.linkedin.com/in/ramahrinaldi/).

Include the affected file or endpoint, the steps to reproduce, and the impact. I will acknowledge the report as soon as I can.

## Supported versions

Only the latest commit on `main` is maintained.

## Secrets

This repository must never contain credentials, tokens, webhooks or database dumps. If you notice one, report it privately as described above.
